# 実機テスト用 読み上げ原稿

iPhone / Mac の実機検証で、アプリ内の録音ボタンから**自然発話**を録音するための原稿。

合成音声（TTS）は kotoba-whisper の分布外入力で出力が崩壊するため（SPIKE.md 参照）、
品質評価には必ず人間の読み上げを使うこと。

読む速度の目安: **日本語 約4.7文字/秒**（普通の会議での発言速度）。
原稿の文字数 ÷ 4.7 ≒ 秒数。極端に速く／ゆっくり読むと RTF の比較可能性が落ちる。

---

## A. スモークテスト（約20秒 / 95字）

最初の1本。まずこれが完走するかだけを見る。落ちる環境ならここで落ちる。

```
お疲れさまです。本日の打ち合わせの内容を録音しています。マイクの入力レベルは問題ないでしょうか。もし聞き取りにくい箇所があれば、後ほど文字起こしの結果を確認して修正してください。
```

---

## B. ベンチマーク比較用（約70秒 / 330字）

**`spike-assets/script.txt` と全く同じ本文。**これを人間が読むことで、同一テキストの
「TTS 版（`public/spike-audio.wav`・70.5秒）」と「自然発話版」を直接比較できる。

- RTX 4080 SUPER / Chrome 150 の実測（turbo q4f16: 8.7秒 / RTF 0.123）と同条件で比較可能
- kotoba の TTS 崩壊がモバイル環境でも同様に再現するか（＝入力の質の問題であって
  ハードウェアの問題ではないこと）を確認できる

```
それでは、定例会議を始めます。本日の議題は三つあります。まず、第一四半期の売上報告です。売上高は前年比十二パーセント増の三千二百万円となりました。特にオンライン経由の受注が好調で、新規顧客は四十五社増加しています。次に、新製品キキフデの開発状況です。開発チームの田中さんから、進捗率は八十パーセントとの報告を受けています。残りの課題は音声認識の精度改善と、画面デザインの最終調整です。リリース予定日は九月十五日を予定していますが、品質検証の結果次第では一週間ほど後ろにずれる可能性があります。最後に、来月の展示会についてです。大阪で開催されるビジネスエキスポに出展します。ブースの設営は佐藤さんが担当し、当日は三名体制で対応する予定です。パンフレットは五百部印刷済みです。以上、何か質問があればお願いします。
```

### 採点ポイント（B）

書き起こし結果を原稿と突き合わせ、以下が取れているかを見る。

| 分類 | 期待される出力 |
|---|---|
| 数値 | 12パーセント / 3200万円 / 45社 / 80パーセント / 500部 |
| 日付 | 9月15日 |
| 固有名詞 | キキフデ、田中、佐藤、大阪、ビジネスエキスポ |
| 頻出誤り | 「第一四半期」→「第1四半期」等の表記ゆれは**誤りとみなさない** |

## C. 難易度高（約40秒 / 190字）

同音異義語・カタカナ専門用語・アルファベットの混在。turbo と kotoba の日本語性能差が
出るとすればここ。余力があれば実施する。

```
今期の方針について、公演ではなく講演の依頼が三件来ています。いずれも機械学習の推論をブラウザ側で行う話です。技術的には、ウェブジーピーユーとオンネックスランタイムを使い、音声データを外部に送信しない構成を想定しています。以降の対応は、意向を確認した上で、移行スケジュールと合わせて再検討します。
```

### 採点ポイント（C）

| 箇所 | 見るべき点 |
|---|---|
| 公演 / 講演 | 文脈から「公演ではなく講演」と正しく書き分けられるか |
| 以降 / 意向 / 移行 | 3つの「いこう」を文脈で判別できるか |
| ウェブジーピーユー | WebGPU と表記できるか（できなくても実用上は問題なし） |

## 読み上げ時の注意

- **静かな部屋で、スマホから20〜30cm 離して読む。**環境ノイズは Whisper の幻覚
  （実際には発話されていない文の生成）の主因になる
- 句読点で**明確に区切る**。棒読みにせず、会議で発言するつもりで抑揚をつける
- 読み直し・言い直しはそのままでよい（実運用でも起きるため、むしろ現実的な入力）
- 録音の長さを控えておく（RTF = 処理時間 ÷ 音声長 の算出に必要）

## 自然会話サンプル（複数話者）を実機で使いたい場合

kotoba-tech 公式サンプル（26.6秒・複数話者）は公開 URL があるため、
**iPhone の Safari で直接開けばファイルアプリに保存できる**（PC からの転送不要）。

```
https://huggingface.co/kotoba-tech/kotoba-whisper-v2.2/resolve/main/sample_audio/sample_diarization_japanese.mp3
```

RTX 4080 SUPER での実測は kotoba RTF 0.300 / turbo RTF 0.084。
